# منصة مدرسة التناغة الشرقية الثانوية

رابط الموقع: https://phdgxt4-coder.github.io/El_tanagha_school/

## 1) رفع الملفات (مرة واحدة)
ارفع **كل** محتويات المجلد في الـ Repository مباشرة (من غير مجلدات فرعية):
`index.html news.html subject.html style.css script.js platform.js inner.js logo.jpg favicon.png`
وكمان مجلد `.github` (فيه `workflows/pages.yml`). لو مش بتعرف ترفع مجلد، اعمل ملف جديد من GitHub باسم `.github/workflows/pages.yml` والصق محتواه.
(اختياري) صورة مبنى المدرسة باسم `school.jpg` — لو مش موجودة بيظهر الشعار مكانها.

## 2) تفعيل التحديث التلقائي (مرة واحدة)
Repository ← **Settings** ← **Pages** ← في **Source** اختار **GitHub Actions**.
بعد كده كل ما ترفع أو تعدّل أي ملف (Commit على فرع `main`) الموقع بيتحدث لوحده خلال 1–2 دقيقة.
تابع التقدم من تبويب **Actions**: علامة خضراء = اتنشر، علامة حمراء = افتح الـ run وشوف الخطأ.

## 3) لو الموقع ما اتحدثش
- استنى دقيقتين وبعدين اعمل تحديث للصفحة (Ctrl+F5 / على الموبايل اقفل التبويب وافتحه).
- تأكد من تبويب Actions إن آخر run أخضر.
- لو اسم الفرع عندك `master` غيّر `main` إلى `master` في `pages.yml`.
- الموقع نفسه بيفحص `version.json` كل دقيقتين وبيعمل إعادة تحميل لو في نسخة جديدة، وبيمسح أي Service Worker قديم (ده غالبًا سبب التعليق في النسخة القديمة).

## 4) الدخول والأدوار
- **طالب / مدرس / ولي أمر**: إنشاء حساب برقم الهاتف (11 رقم يبدأ بـ 01) وكلمة مرور. ولي الأمر بيكتب رقم هاتف ابنه، والابن لازم يكون مسجّل بنفس الرقم.
- **مدير**: حساب افتراضي `01000000000` / `admin123` — **غيّر كلمة المرور فورًا** من الملف الشخصي.

## 5) إزاي تستخدم كل دور
- **المدرس**: رفع PDF (حتى 1.2MB أو رابط) • فيديو YouTube (الصق الرابط) • دروس نصية • واجبات • امتحانات • بنك أسئلة • حضور • تصحيح • إحصائيات • إشعارات.
- **صيغة الأسئلة** (سطر لكل سؤال): `السؤال | خيار 1 | خيار 2 | خيار 3 | رقم الإجابة الصحيحة`
- **الطالب**: المواد، فيديوهات، كتب، واجبات (تسليم نصي)، امتحانات بتصحيح تلقائي، درجات، جدول، إشعارات، بحث، مفضلة، ملف شخصي، إعدادات (وضع ليلي).
- **ولي الأمر**: حضور ودرجات وواجبات الابن، رسائل للمدرسة، إشعارات، تقرير للطباعة.
- **المدير**: مستخدمين، أخبار، مواد وجدول، إحصائيات وتقارير، رسائل، نسخ احتياطي واسترجاع.

## 6) مهم: حدود النسخة الحالية
البيانات متخزنة في **متصفح كل جهاز** (localStorage)، يعني اللي يرفعه المدرس على جهازه **مش هيظهر** للطلاب على أجهزتهم. ده مناسب كتجربة وعرض فقط.
للتشغيل الحقيقي لازم ربط قاعدة بيانات سحابية (Firebase: Authentication + Firestore + Storage). كل التعامل مع البيانات في أول ملف `platform.js` (الدوال `L` `S` `A` `X` `U`) فربط Firebase بيكون بتبديلها فقط. قولّي وأعمل لك الربط.
خد نسخة احتياطية دورية من لوحة المدير.

## ملفات المشروع
`index.html` الرئيسية والدخول • `news.html` `subject.html` + `inner.js` الصفحات الداخلية • `script.js` الدخول والجلسة • `platform.js` لوحات الأدوار • `style.css` التصميم • `.github/workflows/pages.yml` النشر التلقائي.
